## E. Evaluasi picomatch

Sumber primer: https://github.com/advisories/GHSA-fc5q-39xc-vjpf (diperiksa 18 November 2026): affected <=4.0.7, patched None.

Metadata npm saat pemeriksaan:

- UniversalProvider stabil terbaru 2.26.0; keyvaluestorage terbaru 1.1.1 masih bergantung `unstorage:^1.9.0`.
- unstorage 1.17.6 memakai anymatch ^3.1.3. Picomatch latest 4.0.7 masih terdampak.
- Tag latest unstorage menunjuk 2.0.0-beta.0, di luar rentang semver WalletConnect dan belum terbukti kompatibel. Tidak dipaksakan melalui override.
- Mengganti UniversalProvider dengan sign-client tidak menghapus jalur core/keyvaluestorage. Menghapus wallet, memindahkan klasifikasi dependency untuk menyembunyikan audit, shim kosong, atau downgrade paksa 2.17.0 bukan perbaikan terverifikasi.
- Risiko advisory adalah ReDoS ketika glob dan string berbahaya diproses matcher. Bundle browser sekarang tidak mengeluarkan modul rentan, tetapi dependency terpasang masih memuatnya; containment tidak menyelesaikan audit atau memberi exception.

Issue #39 tetap terbuka. Dibutuhkan rilis upstream kompatibel atau pengganti yang ditinjau dan diuji; semua gate lain tidak dapat menutupi audit gagal.
